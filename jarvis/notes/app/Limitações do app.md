# Limitações do app

- Os dados moram no navegador daquele iPad. Restaurar o aparelho ou limpar os dados do Safari apaga tudo — por isso o backup semanal não é opcional.
- Não há sincronização entre aparelhos nem login: é captura local, com exportação manual para o [[REDCap]].
- Não é dispositivo médico nem substitui o prontuário. O registro legal continua sendo o Tasy.

Ver [[Exportação de dados]] e [[Regras do app]].
