# Exportação de dados

Casos → Exportar dados abre três saídas:
- Copiar — cola direto numa planilha
- Baixar CSV — separador ponto e vírgula, com BOM (abre certo no Excel em português)
- Backup JSON — cópia integral, para não depender de um aparelho só

O CSV vai para o [[REDCap]]. Os escores saem em colunas próprias, prefixadas com _: `_rts_t`, `_rts_ponderado`, `_iss`, `_triss_ps`, `_triss_coef`, `_shock_index`, `_rabt`.

Exporte ANTES de qualquer atualização do app e antes de limpar dados do Safari. Ver [[Limitações do app]].
