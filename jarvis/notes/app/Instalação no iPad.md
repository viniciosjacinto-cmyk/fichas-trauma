# Instalação no iPad

Caminho confiável: publicar os quatro arquivos num endereço HTTPS (GitHub Pages) e abrir no Safari.

1. Repositório no GitHub com os quatro arquivos na raiz.
2. Settings → Pages → Source: branch main, pasta /root.
3. Sai um endereço https://<usuário>.github.io/<repo>/.
4. No iPad, abrir no Safari (no iOS só o Safari instala).
5. Compartilhar → Adicionar à Tela de Início.
6. Abrir pelo ícone uma vez com internet; daí em diante funciona offline.

Não abrir o index.html pelo app Arquivos: o iOS trata cada abertura como origem diferente e os casos podem sumir.

Ao publicar versão nova, trocar o número em CACHE no sw.js — senão o iPad continua servindo a versão antiga. Ver [[Ficha de Trauma]] e [[Configuração do iPad]].
